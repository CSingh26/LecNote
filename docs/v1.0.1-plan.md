# v1.0.1 implementation

Work occurs only in the isolated `v1.0.1` checkout. The currently running app,
its checkout, dependencies, and library are not modified.

## Six verified pushes

1. Class resource storage and explicit lecture preparation.
2. Full-lecture relevance, review overrides, and efficient OpenAI generation.
3. Ordered recording merges and safe six-hour audio compression.
4. Class resources and preparation interface.
5. Relevance review, merge, and storage controls.
6. Integration tests, documentation, and branch CI verification.

## Safety and behavior

- Recording finalization transcribes locally without automatically generating notes.
- Generating notes requires a recording note or explicitly selected class resources.
- All transcript content is preserved; uncertain relevance remains reviewable.
- Merging preserves source lectures and absolute source provenance.
- Compression is eligible six hours after finalization, never while recording or
  processing. Replacement follows complete audio validation; failures retain originals.
- Existing custom model settings remain unchanged. New installations use a stronger
  mini-tier OpenAI model with bounded prompts and reusable analysis caches.
- Tests and previews use synthetic data in the isolated checkout.
