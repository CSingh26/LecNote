# LecNote v1.0.0

LecNote turns recorded lectures into a searchable, course-organized study
library. Whisper transcribes audio locally; an OpenAI API key enables generated
notes, examples, definitions, and review questions.

## Highlights

- Record a microphone, browser-shared lecture audio, or both. Pause and resume
  without adding silence to the saved recording.
- Keep transcripts, generated notes, source audio, and course assignments in a
  local library. Regeneration preserves the last successful notes.
- Review timestamped transcripts, attach materials, search lectures, and export
  Markdown, HTML, PDF, or JSON.
- Use the desktop Web UI, CLI, or the versioned GHCR container image.

## Getting started

See the [README](https://github.com/CSingh26/LecNote#readme) for direct install
and container instructions. Add an OpenAI API key in Settings for generated
notes. Transcription itself needs no OpenAI key.

The container image is `ghcr.io/csingh26/lecnote:1.0.0`. Its data directory is
`/data`; mount a persistent volume there. The image does not include model
weights or credentials. The first local Whisper run downloads the selected
model into that volume.

## Limits

The browser must stay open during live recording. Shared lecture audio depends
on browser and operating-system support. Speaker detection is optional and not
included in the container image.
