# LecNote v1.0.1

A class-centered study workflow with reusable materials, full-lecture relevance
review, compact recording merges, and automatic audio storage management.

## Highlights

- Store uploaded materials and reusable typed notes by class.
- Prepare each lecture with a recording note and/or selected class resources
  before explicitly generating study notes. Recording and import still transcribe
  locally, but no longer automatically start paid note generation.
- Analyze the whole lecture before distinguishing course content, class logistics,
  off-topic discussion, and uncertain content. Review and override classifications
  without deleting any original transcript or audio.
- Merge two to twenty ordered recordings from the same class into compact AAC
  audio, preserving source lectures, transcript timestamps, and source history.
- Automatically compress eligible audio six hours after finalization, only while
  idle. Replacements must pass full decoding and duration checks and save space.
  Workspace and class settings can disable this lossy compression.
- Default new installations to GPT-5.4 mini with low reasoning effort, bounded
  context, and reusable analysis caches. Existing model preferences stay unchanged.

## Reliability

Saved notes survive failed regeneration. Completed transcription and relevance
analysis are recoverable when later processing fails. Merge timing is verified
across macOS and Linux, including FFmpeg progress timestamp differences.

The release workflow runs backend, frontend, browser, and isolated API/UI checks
before building and publishing the container. Tests use synthetic audio and
deterministic AI responses; live model quality is not guaranteed by those tests.

## Upgrade

Finish and save any active recording, then back up your local library before
updating and restarting. Publishing this release does not change an already-running
installation. Choose GPT-5.4 mini explicitly in Settings to switch an existing
installation to the new default.

The container is `ghcr.io/csingh26/lecnote:1.0.1`, also tagged `v1.0.1` and `latest`.
Persist `/data` for recordings, notes, settings, and downloaded Whisper models.
No credentials or model weights are bundled in the image.

See the [workflow and upgrade guide](https://github.com/CSingh26/LecNote/blob/v1.0.1/docs/v1.0.1.md)
for limits, compression behavior, and privacy details. Whisper and audio processing
remain local; OpenAI receives transcript and selected supporting text for notes.
