# Academic Field Guide review captures

Captured from the implemented UI by `web/tests/field-guide.spec.ts`, using only
the synthetic library in `web/tests/fixtures/demo-library.ts`. These captures
contain no real lectures, recordings, credentials, or private library data.

The eight library/reader PNGs cover Library and the reading workspace in light and dark themes
at 1440px desktop and 390px phone widths. Motion is disabled and fonts are loaded
before capture. They are implementation evidence, not generated design comps.

The older images in the parent directory document the previous Course Editions
design and are retained as historical evidence.

`recording-320.png` additionally documents synthetic microphone/shared-audio
capture at 320px. The header uses a compact bee mark while retaining the
accessible LecNote link name and the elapsed recording time.
